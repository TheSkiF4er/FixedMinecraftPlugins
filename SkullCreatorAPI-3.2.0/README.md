# SkullCreatorAPI 3.2.0 — SkiF4er Custom Heads Fix

**Статус:** модифицированная Java-библиотека с сохранением лицензии
оригинального MIT-проекта.

Исправление предназначено для совместимости `PlayerProfile` / `PlayerTextures`
в новых версиях Minecraft/Paper, включая 1.21.9+.

Изменён класс `com/skullcreator/internal/util/TexturePropertyWriter.class`.
Реализация использует Bukkit-профили и резервные способы установки текстур
без обязательного обращения к `GameProfile#getProperties`.

## Подключение

`SkullCreatorAPI-3.2.0-SkiF4er.jar` — **библиотека, а не самостоятельный
Bukkit/Paper-плагин**: внутри JAR нет `plugin.yml` или `paper-plugin.yml`.

Подключите модифицированный JAR вместо исходной версии библиотеки к проекту,
который использует SkullCreatorAPI, в соответствии с его механизмом загрузки
зависимостей. Если библиотека встраивается в другой плагин (shading), потребуется
заменить зависимость и заново собрать этот плагин. Простое копирование JAR
в `plugins/` не устанавливает его как отдельный серверный плагин.
