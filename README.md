# FixedMinecraftPlugins (FMP)

Неофициальные исправления ошибок и несовместимостей Minecraft-плагинов.
Это **публичный** репозиторий: материалы сторонних правообладателей публикуются
только с учётом применимых лицензий.

| Компонент | Версия | Публикуемые материалы | Лицензия оригинала |
| --- | --- | --- | --- |
| [SkullCreatorAPI](SkullCreatorAPI-3.2.0/) | 3.2.0 | Исправленный JAR и SHA-256 | MIT |
| [ExcellentCrates](ExcellentCrates-6.6.1/) | 6.6.1 | Изменённый Java-файл, исходный патч, инструкция воссоздания полного исходного дерева.  Исправленный JAR и SHA-256 | GPL-3.0 |

## Воссоздание исходников ExcellentCrates

```bash
bash scripts/reconstruct-excellentcrates.sh
```

Команда загрузит upstream-репозиторий по закреплённому коммиту и применит проверенный
патч. Для сборки после этого нужны Java 21, Maven и доступ к зависимостям upstream.
**Это не означает**, что предоставленное исправление прошло полную сборку, E2E-тесты
или что собранный бинарник идентичен ранее изменённому JAR.
