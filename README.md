# FixedMinecraftPlugins (FMP)

Неофициальные исправления ошибок и несовместимостей Minecraft-плагинов.
Это **публичный** репозиторий: публикация сторонних компонентов допускается
только в рамках их лицензий и прав на распространение.

| Компонент | Версия | Содержимое | Лицензия оригинала |
| --- | --- | --- | --- |
| [SkullCreatorAPI](SkullCreatorAPI-3.2.0/) | 3.2.0 | Модифицированная Java-библиотека (JAR), SHA-256 | MIT |
| [ExcellentCrates](ExcellentCrates-6.6.1/) | 6.6.1 | Модифицированный JAR, изменённый Java-файл, патч, SHA-256 | GPL-3.0 |

## Использование

1. Откройте каталог нужного компонента и прочитайте его `README.md`.
2. Сверьте контрольную сумму JAR с `SHA256SUMS.txt` в том же каталоге.
3. Учитывайте способ подключения: SkullCreatorAPI — **библиотека**, а не
   самостоятельный Bukkit/Paper-плагин.
