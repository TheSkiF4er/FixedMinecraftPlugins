# FMP — Fixed Minecraft Plugins

Исправления ошибок и несовместимостей Minecraft-плагинов. Публичный репозиторий включает **только материалы, для которых проверены условия распространения**.

| Проект | Версия | Исправление | Статус | Лицензия оригинала |
| --- | --- | --- | --- | --- |
| [SkullCreatorAPI](plugins/SkullCreatorAPI-3.2.0/) | 3.2.0 | Custom Heads / PlayerProfile compatibility | JAR доступен | MIT |
| [ExcellentCrates](fixes/ExcellentCrates-6.6.1/) | 6.6.1 | Hologram Spawn Vector | Описание доступно; JAR не опубликован | GPL (проверить точную версию при сборке) |

**FMP не является официальным репозиторием авторов перечисленных плагинов.** Права на оригинальный код принадлежат соответствующим правообладателям. Автор исправлений: SkiF4er.

## Распространение

- SkullCreatorAPI основан на [SkullCreator](https://github.com/nicholasveronico/SkullCreator) (исходный проект diamondpixel) под MIT; лицензионное уведомление сохранено в [`LICENSES/SkullCreator-MIT.txt`](LICENSES/SkullCreator-MIT.txt).
- ExcellentCrates опубликован под GPL, но **изменённый JAR намеренно не включён**, пока не будут представлены соответствующие исходники версии 6.6.1 с исправлением и выполнены условия GPL.
- Файлы, на распространение которых нет подтверждённых прав, здесь не публикуются.
- Единой лицензии на весь репозиторий нет: правовой режим определяется лицензией каждого исходного компонента и условиями внесённых изменений.

## Проверка артефактов

```bash
python3 tools/verify_release.py
```

Скрипт проверяет разрешённый список бинарных файлов, контрольные суммы, целостность JAR и наличие лицензионного уведомления. **Он не заменяет юридическую проверку и E2E-тесты на Minecraft/Paper-сервере.**

## Установка

Порядок установки и ограничения описаны отдельно для каждого исправления. Проверяйте совместимость на тестовом сервере до применения на production.

## Вклад и безопасность

Присылайте исправления через pull request с указанием оригинального проекта, версии, лицензии и исходного кода. Не загружайте сторонние проприетарные JAR, секреты, приватные серверные конфиги или персональные данные. Лицензионные вопросы решаются до добавления бинарных артефактов.
